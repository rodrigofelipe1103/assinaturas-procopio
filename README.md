# Gerador de Assinaturas - Grupo Procópio

Site desenvolvido para facilitar a criação e padronização das assinaturas de e-mail do Grupo Procópio.

## Funcionalidades

- Preenchimento dos dados do colaborador
- Geração automática da assinatura
- Padronização visual das assinaturas
- Utilização das identidades visuais das empresas do Grupo Procópio

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Estrutura do projeto

- `index.html` — página principal do sistema
- `imagem/` — imagens e elementos utilizados nas assinaturas
